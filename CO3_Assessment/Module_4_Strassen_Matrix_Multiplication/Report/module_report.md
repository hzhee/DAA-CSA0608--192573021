# Module 4 Strassen Evidence

Strassen reduces 1,024 x 1,024 scalar multiplications from 1,073,741,824 to 282,475,249, while growing as `Θ(n^2.807)`. A hybrid cutoff is recommended because additions, temporaries, caching and numerical error can outweigh its asymptotic advantage.
