REFLECTION ( 95 words)
Held-Karp replaces repeated route enumeration with overlapping subset states. Each state DP[S,j] stores the cheapest partial tour ending at j after visiting S, and a predecessor reconstructs an optimal route. The method is exact, so it also provides a useful benchmark for heuristics on small instances. Its cost is exponential: with m delivery locations it stores O(m 2^m) states and takes O(m^2 2^m) time. It fits small routing problems where optimality matters and memory is sufficient; for hundreds of locations, multi-start construction plus local improvement is more practical when a fast, high-quality tour is acceptable.
