# CO4 Assignment 4B

Six individual programs and a detailed report for CO4 Assignment 4B.

## Contents

- `Source_Code/Task_1` — Word Wrap dynamic programming
- `Source_Code/Task_2` — Fractional greedy and 0/1 knapsack dynamic programming
- `Source_Code/Task_3` — Dijkstra, Bellman–Ford, Floyd–Warshall, and Warshall routing analysis
- `Source_Code/Task_4` — Two-line assembly scheduling dynamic programming
- `Source_Code/Task_5` — Kruskal, Prim, and Borůvka minimum spanning trees
- `Source_Code/Task_6` — Held–Karp traveling salesperson design challenge
- `Report/CO4_Assignment_4B_Report.pdf` — completed report in the supplied sample format

Each task folder contains `task_N.py`, language-independent `pseudocode.md`, and `Output/` with the full execution text and paginated screenshots.

## Run

From this folder, execute one program with `python3 Source_Code/Task_N/task_N.py`, replacing `N` with 1–6. Regenerate all execution logs and screenshots with:

```sh
python3 Source_Code/generate_outputs.py
```

The programs use Python 3 and its standard library. The screenshot generator uses Pillow.
