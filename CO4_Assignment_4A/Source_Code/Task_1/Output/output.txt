TASK 1 - ALGORITHM DESIGN REVIEW
Deficiencies in the proposed pseudocode:
  1. Inputs are unspecified: package records and vehicle capacity have no defined fields or types.
  2. Arrange packages gives no ordering rule, so different implementations may choose different packages.
  3. Select the best package does not define best; it must compare value per unit weight.
  4. Suitable package does not state the feasibility test against remaining capacity.
  5. The design does not say that a package may be split when only part of its weight fits.
  6. Remaining capacity is not updated after each choice, so the loop can overfill or fail to progress.
  7. The result construction and objective value are undefined, and the loop has no precise stop condition.

Greedy rule: process packages by decreasing value/weight ratio.
